CINDERLINE is a round-based tactical FPS in the browser: Vanguard attacks, Sentinel defends, and the Core Charge is planted at the Kiln (Site A) or the Gantry (Site B) on the Smelter Yard map. Nine bots play the other seats, money earned each round buys rifles, shotguns, a marksman rifle, kevlar and grenades, and the first team to 5 rounds takes the match. Rifles support aim-down-sights; bots hold positions, rotate on gunfire, and throw frags and smoke of their own.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```
